# Class Description / クラス説明書生成ツール

JSON-like Comment Outs と実装内部の通常コメントを解析し、クラスごとの Markdown 説明書を生成するサポートツールです。

**コメントをきちんと書けば、そのコメントから仕様書・説明書を生成できる**ことを目指します。

逆に仕様を先に作る場合は、クラスや関数のコメントを先に記述し、それを仕様書として出力してから実装へ進む使い方も想定します。

**Status: Design Draft — 未実装**

このツールは**コメント解析ツール**です。

コードの実装内容がコメント通りか、処理が正しいか、責務が適切かは検証しません。
