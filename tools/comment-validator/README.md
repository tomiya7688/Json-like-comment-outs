# Comment Validator / コメント検証ツール

**Status: Planned — まだ実装されていません。**

JSON-like Comment Outs の不足や、コメントと実装の**機械的に確認できる不一致**を検出するツールです。

## やりたいこと

例えば次を検出します。

- クラス / 関数 / メソッドに必要なコメントがない
- 必須の Semantic Key がない
- コメントに書かれた引数名と、実際の引数名が違う
- 実装に存在する引数がコメントにない
- コメントにだけ存在する引数がある
- Fields に書かれたフィールド名と実際のフィールド名が一致しない
- 戻り値があるのに Return 相当の説明がない
- SemanticKeys の alias が重複している

コメント不足の一覧や、Coverage のような集計も将来的に出せるようにしたいです。

## 検証しないこと

**形式の違いはエラーとして数えません。**

例えば、

```text
責務:
```

と、

```text
Responsibility:
```

が SemanticKeys によって同じ意味として解決できるなら、違いとして扱いません。

また、次のような自然言語の意味までは検証しません。

- 責務の文章が本当に実装内容と一致するか
- Action の説明が実際の処理を正しく表現しているか
- コメントの文章品質

このツールは、名前・個数・存在有無など**機械的に比較できる範囲**を検証します。
